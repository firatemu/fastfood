## Stitch actions that must not fake success

| Stitch control              | Backend                              | A1+ rule                                                      |
| --------------------------- | ------------------------------------ | ------------------------------------------------------------- |
| TELEMETRY ACTIVE / live SLA | No WS/SSE                            | Show last poll / last load time                               |
| Global search               | Disabled placeholder today           | Keep disabled until an API exists                             |
| Kitchen reject              | `CANCELLED` transition if FSM allows | Call transition; surface domain error                         |
| Courier QR                  | Courier claim API, not Admin         | Not applicable on Admin unless a real admin endpoint is added |
| Product availability toggle | GET+PATCH                            | `/branches/availability`; no mock / no bulk                   |
| HQ all-branch orders        | `branchId` required                  | No fake “all branches” list                                   |
