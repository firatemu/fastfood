# Customer capability matrix

Canonical inventory of BURGER HOME customer capabilities across backend, `apps/storefront-web`, and `apps/customer-mobile`.

Machine-readable source: `@fastfood/contracts` `CUSTOMER_CAPABILITY_REGISTRY` (`packages/contracts/src/customer-capability-registry.ts`).

Seeded from `docs/storefront-rebuild/04_CAPABILITY_GAP_MATRIX.md` and `docs/mobile-rebuild/04_MOBILE_CAPABILITY_MAPPING.md`. Do not invent capabilities.

Impact and implementation status are separate.

## Impact

| Value                     | Meaning                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------ |
| `AUTOMATICALLY_SUPPORTED` | Existing client already consumes the API/renderer; a data update flows without client code |
| `CHANGE_REQUIRED`         | This client needs or needed a code/config change for the capability                        |
| `NOT_APPLICABLE`          | Platform-specific (browser-only or native-only). Not a synonym for blocked                 |

## Implementation status

| Value                                    | Meaning                                                                    |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| `IMPLEMENTED`                            | Shipped in this client                                                     |
| `IMPLEMENTED_WITH_INTENTIONAL_DEVIATION` | Shipped with an approved honest deviation                                  |
| `EXTERNAL_PROVIDER_BLOCKED`              | Required, blocked on credentials/provider. Pair with `CHANGE_REQUIRED`     |
| `DEFERRED_WITH_APPROVED_REASON`          | Explicitly not in current product                                          |
| `NOT_RELEVANT`                           | Not a customer surface on this client                                      |
| `MISSING`                                | Forbidden in the completed baseline (`pnpm check:customer-platform` fails) |
